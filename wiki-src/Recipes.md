# Recipes

`I` = iron ingot, `R` = redstone, `G` = glass pane, `D` = diamond, `C` = chest, `P` = piston, `T` = crafting table.

## Network

| Item | Recipe |
|---|---|
| Network Controller | Shaped: `IRI / RDR / IRI` |
| Cable (×4) | Shaped: `I R I` (one row) |
| Drive | Shaped: `III / ICI / IRI` |

## Storage cells

| Item | Recipe |
|---|---|
| 1k Cell | Shaped: `GRG / R_R / III` (centre empty) |
| 4k Cell | Shapeless: 1k Cell + 2 gold ingots + 2 redstone |
| 16k Cell | Shapeless: 4k Cell + 2 diamonds + 2 redstone |
| 64k Cell | Shapeless: 16k Cell + 2 diamonds + 2 emeralds |
