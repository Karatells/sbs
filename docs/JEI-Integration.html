JEI Integration#

If JEI is installed, the "+" button in a recipe sends it to the Pattern Encoding Terminal (the terminal must be open):

JEI recipe Encoder mode
Crafting table Crafting
Furnace, blast furnace, smoker, stonecutter Processing (inputs + result)

JEI is optional. The mod compiles against the JEI API only; without JEI everything else works normally.
