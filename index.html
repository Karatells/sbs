Идея модаThe idea

Во многих системах хранения ячейка ограничена не только числом предметов, но и числом уникальных типов. Здесь второго лимита нет — ни для предметов, ни для жидкостей. In many storage systems a cell is limited not only by the number of items but also by the number of unique types. Here the second limit does not exist — neither for items nor for fluids.

Без лимита типовNo type limit

В одну ячейку помещаются сотни разных предметов (или любых жидкостей), пока не закончится её байтовая ёмкость.A single cell can hold hundreds of different items (or any number of fluid types) until its byte capacity runs out.

1 предмет = 1 байт · 1 000 mB = 1 байт1 item = 1 byte · 1,000 mB = 1 byte

Прозрачное правило: стак в 64 булыжника стоит 64 байта, как и 64 разных предмета по одной штуке. Одно ведро жидкости (1 000 mB) — ровно 1 байт.A transparent rule: a stack of 64 cobblestone costs 64 bytes, and so do 64 different single items. One bucket of fluid (1,000 mB) is exactly 1 byte.

used_bytes = Σ item_count  |  fluid_bytes = Σ fluid_mB / 1000
Пример: ячейка 1k (1 024 байта) вмещает 500 булыжника + 400 земли + 124 алмаза = ровно 1 024 предмета. Ячейка 1M вмещает 1 048 576 любых предметов. Example: a 1k cell (1,024 bytes) holds 500 cobblestone + 400 dirt + 124 diamonds = exactly 1,024 items. A 1M cell holds 1,048,576 items of any kind.

function tick() {
  var e = net.energy();
  display.set(0, "Energy: " + e.percent + "% (" + e.stored + " FE)");
  display.set(1, "Free bytes: " + net.freeBytes());
  // Output redstone signal when energy drops below 30%
  redstone.set("north", e.percent < 30 ? 15 : 0);
}

function onAlert(ev) {
  var hits = Number(store.get("alerts") || 0) + 1;
  store.set("alerts", String(hits));
  display.set(2, "Last alert (#" + hits + "): " + ev.text);
